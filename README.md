# 🛍️ [Маркетплейс (Интернет-магазин)](https://marketplace-frontend-vannesals-projects.vercel.app/)

## Описание

Современный маркетплейс спортивного питания, построенный на передовых технологиях.

## ✨ Возможности

- ⚡ **Молниеносная скорость** - на базе Vite и React 19
- 🎨 **Красивый интерфейс** - стилизация с TailwindCSS
- 🏗️ **Типизация** - разработан на TypeScript
- 🚀 **Управление состоянием** - интеграция Redux Toolkit
- 🛣️ **Роутинг** - React Router v7
- 🍪 **Аутентификация** - сессии на основе cookies
- ✨ **Анимации** - плавные переходы с Framer Motion

## 🛠 Технологии

### Фронтенд
- `React 19` + `Vite`
- `Redux Toolkit` + `React-Redux`
- `React Router v7`
- `Tailwind CSS` с плагинами
- `Framer Motion` для анимаций
- `ESLint` + `Prettier` для линтинга

### Бэкенд
- `Node.js` + `Express`
- `Sequelize ORM` (PostgreSQL)
- `Express Session` + `CORS`
- `Cookie-parser` + `JWT`
- `Sequelize CLI` для миграций

## 🚀 Начало работы

### Требования
- Node.js (рекомендуется v18+)
- npm/yarn/pnpm

## 🚀 Установка и запуск

### Frontend (папка `marketplace/frontend`)
```bash
cd frontend
npm install
npm dev # режим разработки
npm build # сборка для продакшена
```

### Backend (папка `marketplace/backend`)
```bash
cd backend
npm install
npm dev 
```
