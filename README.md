![React](https://img.shields.io/badge/React-19.0.0-blue?logo=react)

Современный маркетплейс, построенный на передовых технологиях.
https://marketplace-frontend-vannesals-projects.vercel.app/

## ✨ Возможности

- ⚡ **Молниеносная скорость** - на базе Vite и React 19
- 🎨 **Красивый интерфейс** - стилизация с TailwindCSS
- 🏗️ **Типизация** - разработан на TypeScript
- 🚀 **Управление состоянием** - интеграция Redux Toolkit
- 🛣️ **Роутинг** - React Router v7
- 🍪 **Аутентификация** - сессии на основе cookies
- ✨ **Анимации** - плавные переходы с Framer Motion

## 🛠️ Технологии

### Основные
- React 19
- TypeScript
- Vite

### Стилизация
- TailwindCSS
- PostCSS
- Autoprefixer

### Состояние и роутинг
- Redux Toolkit
- React Redux
- React Router DOM

### Утилиты
- Framer Motion (анимации)
- js-cookie (работа с cookies)
